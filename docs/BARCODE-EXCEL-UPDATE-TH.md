# อัปเดตเมนูผู้ใช้และ Excel บาร์โค้ด — 30 ตุลาคม 2569

## สิ่งที่เปลี่ยน

- ย้ายปุ่มคำสั่งเพิ่มเติมมาไว้ข้างชื่อผู้ใช้ด้านล่างแถบเมนู เปลี่ยนเป็นจุดแนวตั้ง 3 จุด ไม่มีข้อความกำกับหรือ tooltip เมนูเปิดขึ้นด้านบน และยังใช้คำสั่งเดิมตามสิทธิ์ของผู้ใช้
- ปรับ Excel ในระบบบาร์โค้ดให้ใช้หน้าตาตามรายงานพิมพ์: ชื่อสหกรณ์ ช่องชื่อ/วันที่ สถานะข้อมูล ชื่อรายงาน หัวตารางรวมช่อง พื้นสีเทา เส้นตาราง และแถวสลับสี
- ส่งออกครบ 11 คอลัมน์ รวมช่องจำนวนในระบบ แพ็ค/เดี่ยว กระจาย และของเดิม เพื่อกรอกต่อใน Excel ได้ เก็บรหัสคู่ค้า หมวด และเลขบาร์เป็นข้อความ รักษาศูนย์นำหน้าและเลขยาว
- ใช้ฟอนต์ สัดส่วนคอลัมน์ และความสูงแถวจากการจัดหน้ารายงานพิมพ์ พร้อมตั้งกระดาษ A4 แนวตั้ง พอดี 1 หน้าตามความกว้าง และพิมพ์หัวตารางซ้ำ
- ในแท็บ **เพิ่มและนำเข้า** ใช้ปุ่มส่งออกเดิมได้ทั้งรวมทุกหมวดในชีตเดียวและแยกชีตตามหมวด
- ในแท็บ **ปริ้นรายงาน** มีปุ่ม **ส่งออก Excel** เพิ่ม เลือกหมวดและรหัสคู่ค้าเหมือนตอนปริ้นได้ โดยแยกแต่ละหมวดเป็นคนละชีต

## วิธีอัปเดต

นำไฟล์ภายในโฟลเดอร์ `CMUCOOP-SP-main` ไปแทนที่ไฟล์ใน repository เดิม โดยไม่ซ้อนโฟลเดอร์เพิ่ม รอ GitHub Pages อัปเดตแล้วกด Ctrl+F5

รายการที่แก้ไข: ไฟล์ HTML ที่อ้างถึง dashboard (ปรับเลขเวอร์ชันเพื่อโหลดไฟล์ใหม่), `assets/js/shared/dashboard-v16.js`, `assets/css/shared/dashboard-v16.css`, `assets/js/pages/barcode.js` และไฟล์ใหม่ `assets/js/pages/barcode-export.js`

รอบนี้ไม่ต้องเปลี่ยน Worker หรือฐานข้อมูล ไฟล์ `Cloudflare-Worker/worker-copy.txt` ในชุดนี้เป็นไฟล์ `worker_copy.txt` ที่แนบมาโดยไม่ได้แก้ไข

## ผลตรวจ

- ชุดทดสอบอัตโนมัติ 83 ข้อผ่าน รวมการนำไฟล์รายงานกลับเข้า การรักษาศูนย์นำหน้า/เลขบาร์ยาว หัวตารางรวมช่อง รูปแบบพิมพ์ ชื่อชีตซ้ำ หมวดว่าง และการส่งออก 20,000 รายการ
- ตรวจ syntax, module imports, API และไฟล์อ้างอิงในหน้าเว็บ
- ทดสอบผ่าน Chrome ขนาด 1440 × 1000 และ 390 × 844: ตำแหน่งปุ่ม เมนูเปิดด้านบน การกด Escape/Tab การส่งออกแบบรวม/แยกชีต และการกรองหมวด/รหัสคู่ค้า
- การทดสอบเบราว์เซอร์จับเหตุการณ์ดาวน์โหลดและอ่านไฟล์จาก Blob ที่สร้างจริง เนื่องจากสภาพแวดล้อมทดสอบยกเลิกการบันทึกดาวน์โหลดของ Chrome ลงดิสก์ ตรวจเปิดไฟล์ด้วยตัวอ่าน XLSX และ openpyxl เพิ่มเติม

คำสั่งตรวจ: `npm run verify` และ `npm run test:barcode:browser` (คำสั่งหลังต้องมี Playwright และเบราว์เซอร์ หรือกำหนด `PLAYWRIGHT_PACKAGE_PATH` / `PLAYWRIGHT_CHROME_PATH`)
