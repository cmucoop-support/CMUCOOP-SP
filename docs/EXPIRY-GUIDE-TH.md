# แจ้งเตือนสินค้าหมดอายุ — เชื่อมสินค้าค้างสต็อกและกล้องสแกน

คู่มือการใช้งานระบบวันหมดอายุ สำหรับคำสั่งติดตั้ง โครงสร้างไฟล์ และผลทดสอบฉบับล่าสุด ให้ใช้ README-TH.md และ docs/VALIDATION-TH.md

## หน้าใช้งาน

หน้าแยกคือ `expiry.html` เปิดผ่านการ์ดแจ้งเตือนสินค้าหมดอายุบนหน้าแรก ใช้บัญชีและ session เดิม หรือเข้าสู่ระบบในหน้านี้ได้โดยตรง หลังนำขึ้นเว็บ URL จะเป็น `<URL เว็บเดิม>/expiry.html` ชุดนี้เป็นโค้ดที่แก้และทดสอบในเครื่อง ยังไม่ได้ deploy ไปยังระบบจริง

## สิ่งที่ปรับเพิ่ม

- ชื่อและรหัสสินค้าดึงจากข้อมูลปัจจุบันของ **สินค้าค้างสต็อก** ค้นหาได้ทั้งรหัสและชื่อ เลือกผลแล้วเติมชื่อ/รหัสอัตโนมัติ ถ้าพบหลายรายการจะแสดงรายการให้เลือก
- สาขาเลือกจากข้อมูลและการตั้งค่าสาขาของสินค้าค้างสต็อก รวมสาขาที่ตั้งค่าไว้แต่ยังไม่มีรายงาน และตัดสาขาที่ตั้งค่าลบออก ค้นหาสินค้าในสาขาที่เลือก เปลี่ยนสาขาแล้วต้องเลือกสินค้าใหม่
- ใช้ข้อมูลสินค้าได้แม้คงเหลือเป็น 0 หรือติดลบ ข้อมูลที่ส่งให้หน้าแจ้งเตือนมีเฉพาะรหัส ชื่อ สาขา และหมวด ไม่ส่งต้นทุน ราคา หรือกำไร
- กด **เปิดกล้อง** บนมือถือเพื่อสแกน จากนั้นระบบค้นหารหัสและเติมชื่อสินค้า เลือกวันหมดอายุแล้วบันทึกเอง ไม่บันทึกทันทีหลังสแกน
- รองรับรหัสที่มี P นำหน้าตัวเลขตามการเทียบบาร์ของหน้าสินค้าค้างสต็อก และการอ่าน UPC-A/EAN-13 ที่ต่างกันเฉพาะศูนย์นำหน้า หากบาร์โค้ดบนฉลากต่างจากรหัสในสต็อก ให้ค้นหาด้วยชื่อสินค้าและเลือกรหัสที่ถูกต้อง
- ล็อตเดิมเก็บชื่อ รหัส และสาขาตามตอนบันทึก การนำเข้าสต็อกใหม่หรือเปลี่ยนสาขาไม่เขียนทับหรือปิดแจ้งเตือนล็อตเก่า และยังแก้วันหมดอายุ/จำนวน/หมายเหตุของล็อตเดิมได้

## วิธีบันทึก

1. เลือก **เพิ่มล็อตใหม่** และเลือกสาขา
2. พิมพ์ชื่อ/รหัสแล้วกดค้นหา หรือกด **เปิดกล้อง** แล้วอนุญาตกล้อง เล็งให้เห็นบาร์โค้ดครบแถบ เครื่องสแกนที่ส่งค่าเหมือนแป้นพิมพ์ก็ใช้กับช่องค้นหานี้ได้
3. เลือกสินค้าที่ต้องการ รหัสและชื่อจะถูกเติมอัตโนมัติ ถ้าไม่พบ ให้ตรวจสาขาหรือนำเข้าข้อมูลที่ระบบสินค้าค้างสต็อกก่อน ไม่ต้องสร้างทะเบียนสินค้าแยกในหน้านี้
4. ใส่วันหมดอายุ จุดวาง หมายเหตุ จำนวน และหน่วยใส่หรือไม่ก็ได้
5. กด **บันทึกล็อต** หรือ **บันทึกและเพิ่มถัดไป** สร้างเลข LOT อัตโนมัติ สินค้าและวันที่ซ้ำกันยังบันทึกเป็นล็อตใหม่ได้

ตัวเลขบนการ์ดนับเป็น **ล็อต** จำนวนว่างแสดง “ไม่ระบุ” จำนวน 0 และทศนิยมไม่เกิน 3 ตำแหน่งบันทึกได้ ไม่มีการเพิ่ม ลด หรือตัดจำนวนในสต็อก

**รับทราบ** ยังแจ้งเตือนต่อ **ปิดแจ้งเตือน** หยุดเฉพาะล็อตนั้นและเก็บประวัติ ดูย้อนหลังหรือเปิดใหม่ได้

## กล้องมือถือ

ต้องเปิดเว็บผ่าน **HTTPS** (หรือ localhost ระหว่างพัฒนา) และอนุญาตกล้อง ใช้กล้องหลังเป็นค่าเริ่มต้น ไม่ขอไมโครโฟน ภาพประมวลผลในเบราว์เซอร์ ไม่ส่งภาพกล้องไปยังเซิร์ฟเวอร์

มีทั้งตัวอ่านของเบราว์เซอร์และตัวอ่านสำรอง ZXing 0.23.0 ที่รวมใน `vendor/` ไม่พึ่ง CDN ระหว่างใช้งาน รองรับ EAN-13, EAN-8, UPC-A, UPC-E, Code 128, Code 39 และ ITF ต้องอ่านค่าเดียวกันสองครั้งก่อนยืนยันเพื่อช่วยลดการอ่านผิด เมื่ออ่านสำเร็จ ปิดกล้อง ออกจากหน้า หรือซ่อนแท็บ ระบบหยุดกล้อง

ถ้าไม่ได้อนุญาตกล้อง จะมีคำแนะนำให้เปิดสิทธิ์แล้วลองใหม่ หรือปิดเพื่อพิมพ์ชื่อ/รหัสแทน การสแกนจริงขึ้นกับกล้อง แสง ฉลาก และเบราว์เซอร์ ชุดนี้ทดสอบด้วย Chrome และวิดีโอจากภาพบาร์โค้ดจำลอง ยังไม่ได้ทดสอบกับกล้องโทรศัพท์ iPhone/Android จริง

อ้างอิง: [getUserMedia และสิทธิ์กล้อง](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia), [การรองรับ BarcodeDetector](https://developer.mozilla.org/en-US/docs/Web/API/Barcode_Detection_API), [ZXing library](https://github.com/zxing-js/library)

## ช่วงแจ้งเตือนและสิทธิ์

ช่วงเวลาเดิมครบ: หมดอายุแล้ว, วันนี้–7 วัน, เกิน 7 วัน–1 เดือน, **1–3 เดือน**, **3–6 เดือน**, **6–12 เดือน** ใช้เดือนปฏิทินและเวลาไทย กลุ่มไม่ซ้ำกัน ล็อตเกิน 12 เดือนยังอยู่ในรายการทั้งหมดและมีตัวกรองแยก

ใช้สิทธิ์แจ้งเตือนสินค้าหมดอายุ (ดู) และสิทธิ์เพิ่ม/แก้ไข/รับทราบ/ปิดล็อตจากหน้าตั้งค่าเดิม Admin ใช้งานได้ทันที บัญชีทั่วไปให้ Admin เปิดสิทธิ์ก่อน ผู้ที่มีสิทธิ์ expiry ค้นหาชื่อ/รหัสและสาขาได้โดยไม่ต้องเปิดสิทธิ์ดูต้นทุนในระบบสต็อก สิทธิ์ยังเป็นระดับระบบ ไม่ได้จำกัดผู้ใช้เฉพาะสาขา

แสดงแจ้งเตือนบนหน้าเว็บและการ์ดหน้าแรก โหลดใหม่ทุก 1 นาทีเมื่อแท็บแสดงอยู่ ไม่มีการส่ง LINE/อีเมล/push ขณะปิดเว็บในรุ่นนี้
