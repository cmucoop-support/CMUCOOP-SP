# รายงานตรวจโค้ดและแก้ไขระบบสำรวจราคาตลาด

วันที่ 26 ตุลาคม 2569 (เวลาไทย)

ตรวจจากโครงการ CMUCOOP-SP-main ใน ZIP และ Worker แบบไฟล์เดียวที่แนบมา โดยใช้ฐานข้อมูลจำลองในเครื่อง ไม่ได้แก้ไขข้อมูลหรือ deploy ระบบจริง

## จุดที่แก้ไข

| จุดผิด/ปัญหาเดิม | ผลหลังแก้ |
| --- | --- |
| ชื่อสินค้าและหมายเหตุแคบมาก ข้อมูลตัดบรรทัดจนอ่านยาก สีและเส้นตารางหนาแน่น | จัดหัวตาราง 2 ระดับ แบ่งกลุ่มข้อมูล ใช้สีพื้นอ่อนและแถวสลับ ขยายชื่อสินค้า/หมายเหตุ และปรับความสูงแถวตามข้อความ |

| ตัวบีบอัด ZIP ไม่รอการเขียนข้อมูลจบ | รอการเขียนและปิด CompressionStream โดยอ่านข้อมูลที่บีบอัดไปพร้อมกัน |

ย้ายโค้ดส่งออกไปที่ assets/js/pages/market-export.js และลดชุดสไตล์เก่าที่มีจำนวนมากให้เป็นชุดสไตล์สม่ำเสมอ อ่านและแก้ไขได้ง่ายขึ้น

สูตร “กำไร%” ยังคงคิดเทียบต้นทุนตามระบบเดิม ไม่ได้เปลี่ยนไปหารด้วยยอดขาย เฉลี่ยเฉพาะสินค้าที่มีคงเหลือและต้นทุนมากกว่า 0 ราคาแนะนำจะถูกใช้เฉพาะสถานะปรับขึ้น/ปรับลง/ฝากพิจารณาที่มีราคามากกว่า 0

## ผลตรวจ

- ตรวจ syntax ของ JavaScript และ script ใน HTML ทั้งโครงการ และตรวจการ import โมดูล Worker ผ่าน
- ตรวจชื่อ API ที่หน้าเว็บเรียกเทียบกับ Worker 115 คำสั่ง ไม่พบ API ขาดหรือ local asset หาย
- ชุดทดสอบ Node ผ่าน 77/77 ข้อ รวมสิทธิ์ผู้ใช้ การเขียนข้อมูลพร้อมกัน การ rollback และข้อมูลจำลองขนาดใหญ่
- เพิ่มการทดสอบไฟล์ส่งออก/นำกลับเข้า รหัสมีศูนย์นำหน้า รหัสยาว วันที่ ข้อความพิเศษ หมายเหตุ ต้นทุน 0 ชื่อชีตซ้ำ ไฟล์ว่าง และส่งออก 2,000 รายการ
- ทดสอบหน้า Export ใน Chrome ครบโหมดแยกชีต รวมชีต ตามตัวกรอง และเลือกแยก/รวม/ข้ามรายหมวด
- เปิดหน้าเว็บทั้ง 11 หน้าในชุดทดสอบ ไม่พบ JavaScript page error
- ชุดทดสอบเบราว์เซอร์เดิมของระบบวันหมดอายุและกล้องอ่านบาร์โค้ดผ่าน
- เปิดไฟล์ตัวอย่างใน Microsoft Excel ได้โดยไม่พบหน้าซ่อมไฟล์ ตรวจรหัส 0012345678901 และ 12345678901234567890 ได้ครบ และสรุปหลังปรับแสดง 27.97% / 19.60% ตรงกับข้อมูลสมมติ
- Worker สำหรับคัดลอกลง Dashboard ตรวจว่าใช้ schema และ API ชุดเดียวกับซอร์ส และผ่านการทดสอบเซสชันสำรองด้วย

## วิธีนำไปอัปเดต

1. แตกไฟล์ CMUCOOP-SP-fixed.zip
2. อัปโหลดไฟล์หน้าเว็บที่เปลี่ยน 3 ไฟล์ โดยคงโครงสร้างเดิม:
   - market.html
   - assets/js/pages/market.js
   - assets/js/pages/market-export.js (ไฟล์ใหม่ ต้องอัปโหลดด้วย)
3. หากใช้ Cloudflare Dashboard ให้นำโค้ดทั้งหมดจาก Cloudflare-Worker/worker-copy.txt ไปแทน Worker เดิมเพื่อรับการแก้เซสชันสำรอง คง D1 binding เดิมไว้ หาก deploy จากซอร์ส ให้ใช้โฟลเดอร์ worker/ ที่แนบมา การแก้ครั้งนี้ไม่ได้เปลี่ยน schema หรือ SCHEMA_VERSION
4. เมื่ออัปโหลดเรียบร้อย กด Ctrl+F5 แล้วลองส่งออกจากหน้าสำรวจราคาตลาด

ไฟล์อื่นที่เปลี่ยนเป็นเอกสาร ข้อกำหนด Node และชุดทดสอบ สำหรับผู้พัฒนาทดสอบซ้ำด้วย:

~~~sh
node worker/scripts/check.mjs
node worker/scripts/audit.mjs
node --test worker/tests/*.test.mjs
node worker/tests/market.browser.e2e.mjs
node worker/tests/browser.e2e.mjs
~~~

การทดสอบเบราว์เซอร์ต้องมี Playwright และ Chrome/Chromium ที่ใช้งานได้ ตั้ง PLAYWRIGHT_PACKAGE_PATH / PLAYWRIGHT_CHROME_PATH ได้หากติดตั้งไว้นอกโครงการ

## ขอบเขตการยืนยัน

- ตัวอย่าง Excel ใช้ข้อมูลสมมติ ไม่ใช่ข้อมูลสำรวจจริง
- Chrome headless ในสภาพแวดล้อมนี้รายงาน canceled แม้ทดลองดาวน์โหลดไฟล์ข้อความทดสอบทั่วไป จึงทดสอบเนื้อหา Blob และลิงก์ดาวน์โหลดจาก UI รวมกับการบันทึกไฟล์ด้วยตัวสร้างเดียวกันและเปิดใน Excel
- ตรวจการตั้งค่ากระดาษ พื้นที่พิมพ์ และหัวซ้ำในไฟล์แล้ว ยังไม่ได้พิมพ์กับเครื่องพิมพ์จริง หน้าตัวอย่างก่อนพิมพ์ของ Excel ใช้ไม่ได้เพราะเครื่องพิมพ์ที่ตั้งไว้ไม่เชื่อมต่อ
- การทดสอบใช้ D1 จำลอง ไม่ได้เชื่อมฐานข้อมูล Cloudflare จริง และยังไม่ได้ deploy ขึ้นเว็บไซต์จริง
