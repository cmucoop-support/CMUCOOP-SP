# ผลตรวจฉบับจัดโครงสร้างและทะเบียนสินค้า

วันที่ตรวจ: 18 ตุลาคม 2569 (เวลาไทย)

## ผลตรวจอัตโนมัติ

| รายการ | ผล |
| --- | --- |
| ชุดทดสอบ Node.js | ผ่าน 80/80; ไม่ข้ามรายการ |
| Syntax และการโหลดโมดูล | ผ่าน: browser scripts 18 ไฟล์, worker/test/tool modules 36 ไฟล์ |
| ตรวจ API และ assets | 111 RPC functions; ไม่พบชื่อ API ที่เรียกแล้วไม่มีใน Worker; ไม่พบ local assets ขาด |
| Migration | 0001–0004 ทำงานต่อกันและคงข้อมูลเดิม; schema 0004 ตรงกับ runtime |
| ชุด browser.e2e.mjs | ผ่าน Chrome จริง รวม barcode decoder, กล้องจำลอง, การบันทึกล็อต, retry, session, มือถือ |
| ชุด catalog.e2e.mjs | ผ่าน Chrome จริง รวมการ์ดหน้าแรก, บันทึกทั้ง 4 ระบบผ่าน RPC, อัปเดตข้ามแท็บ, ตัวกรอง, รายละเอียด, สิทธิ์ และมือถือ |
| หน้าเดิมหลังย้ายไฟล์ | barcode, stock, market, settings, music, sound, banner, tv, receiver โหลดได้โดยไม่มี JavaScript page errors ในการทดสอบ |

## ข้อมูลจำลองขนาดใหญ่

| กรณี | ค่าที่วัดได้ในชุดจำลอง |
| --- | --- |
| ทะเบียน 30,000 รายการ | สร้าง/อ่านสรุปครั้งแรก 38 คำสั่ง; อ่านหน้าที่แคชแล้ว 5 คำสั่งและไม่อ่านตารางต้นทาง |
| ขนาดพารามิเตอร์ทะเบียนสูงสุดในกรณีทดสอบ | 1,799,999 ไบต์ ต่ำกว่าขีดจำกัดค่า 2,000,000 ไบต์ |
| บาร์สินค้า 20,000 แถว | นำเข้า สำเนา export และ restore ผ่าน |
| สต็อก 30,000 แถว | บันทึกแยกสาขา ฉบับก่อนหน้า และ no-change ผ่าน |
| ตลาด 20,000 แถว | บันทึกแบบ chunks, revision, rollback ผ่าน |
| ล็อตหมดอายุ 10,000 รายการ | แบ่งหน้าจากเซิร์ฟเวอร์และค้นหา literal ผ่าน |
| Bulk เขียนบาร์ 2,000 แถว | ตัวบอกการเปลี่ยนแปลงทะเบียนเพิ่ม 1 ครั้งต่อ transaction |
| market แบบร่างแก้ต่อเนื่อง 20 ครั้ง | รวมการ serialize/เขียนที่ตั้งเวลาเป็น 1 ครั้ง; flush ข้อมูลล่าสุดก่อนออกและไม่ข้ามบัญชี |

การทดสอบครอบคลุมการเปลี่ยนแปลงระหว่างสร้าง/อ่านทะเบียน การอ่านพร้อมกัน การย้อนกลับเมื่อเขียนล้มเหลว รักษาข้อมูลต้นทางที่บันทึกสำเร็จ ข้อมูลกลุ่มสต็อกขาด ไม่ส่งข้อมูลต้นทุนให้สิทธิ์ทะเบียน และไม่แปลงชื่อสินค้าจากต้นทางเป็น HTML

ค่าด้านบนเป็นผลจาก Node.js 24, SQLite ในหน่วยความจำ และ Chrome พร้อมระบบ route จำลอง ไม่ใช่ latency, CPU, memory, quota หรือค่าใช้จ่ายที่วัดบน Cloudflare production การตรวจครั้งนี้ไม่ได้ deploy หรือเขียนฐานข้อมูลจริงของร้าน

คำสั่งตรวจซ้ำอยู่ใน README-TH.md และ package.json ภาพตัวอย่างที่ส่งมอบใช้ข้อมูลทดสอบเท่านั้น
