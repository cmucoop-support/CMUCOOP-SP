# ผลตรวจฉบับตัดระบบทะเบียนสินค้าและปรับปรุงการเขียนข้อมูล D1

วันที่ตรวจ: 19 ตุลาคม 2569 (เวลาไทย)

## ผลตรวจอัตโนมัติ

| รายการ | ผล |
| --- | --- |
| ชุดทดสอบ Node.js | ผ่าน 58/58; ไม่ข้ามรายการ |
| Syntax และการโหลดโมดูล | ผ่าน: browser scripts 17 ไฟล์, worker/test/tool modules 30 ไฟล์ |
| ตรวจ API และ assets | 108 RPC functions; ไม่พบชื่อ API ที่เรียกแล้วไม่มีใน Worker; ไม่พบ local assets ขาด |
| Migration | 0001–0003 ทำงานต่อกันและคงข้อมูลเดิม; ลบ Trigger/ตารางทะเบียนสินค้าเดิมอัตโนมัติ |

## ข้อมูลจำลองขนาดใหญ่และการประหยัด Row Writes

| กรณี | ค่าที่วัดได้ในชุดจำลอง |
| --- | --- |
| ดัชนีค้นหาสินค้าในหน้าวันหมดอายุ 30,000 รายการ | สร้างในหน่วยความจำ 8 คำสั่งอ่าน, ค้นหาซ้ำ 4 คำสั่งอ่าน, **เขียนลง D1 = 0 แถว** |
| บาร์สินค้า 20,000 แถว (นำเข้า สำเนา ส่งออก กู้คืน) | นำเข้าครั้งแรก 22 คำสั่ง; นำเข้าซ้ำข้อมูลเดิม 500 แถว เขียนไม่เกิน 5 แถว |
| สต็อก 30,000 แถว | บันทึกแยกสาขา ฉบับก่อนหน้า และ no-change ผ่านใน 28 คำสั่ง |
| ตลาด 20,000 แถว | บันทึกเฉพาะก้อนที่เปลี่ยน พร้อมตรวจ revision และ rollback ใน 33 คำสั่ง |
| คิวเพลง TV Tick ต่อเนื่อง | ไม่เขียน `MUSIC_PROG` ซ้ำทุก 5 วินาทีเมื่อเวลาเดินตามปกติ (เขียน 0 แถวระหว่างเล่นปกติ) |
| เข้าสู่ระบบเมื่อ D1 เกินโควตาเขียนรายวัน | ออกโทเค็นสำรอง `s1.` และเข้าใช้งานอ่านข้อมูลได้ตามปกติ |
