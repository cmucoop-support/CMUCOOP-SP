# ผลตรวจ Dashboard V16

## ขอบเขต

ปรับ HTML ทั้ง 12 หน้า เพิ่มธีม CSS/JS ร่วม ปรับ API adapter ให้แจ้งสถานะ session แก่เมนู และเปลี่ยนสีเริ่มต้นฝั่งแสดงผล TV โค้ด Worker และข้อมูลธุรกิจไม่ได้เปลี่ยน

## การตรวจที่ดำเนินการ

ผลรวม: ชุดทดสอบระบบ 78 รายการผ่านทั้งหมด และชุดทดสอบ DOM/CSS 10 รายการผ่านทั้งหมด รวม 88 รายการ ไม่มีรายการล้มเหลว

- ตรวจ syntax ของ JavaScript ทั้ง browser และ Worker พร้อม import โมดูล
- ตรวจ API ที่ถูกเรียกและไฟล์อ้างอิงใน HTML/CSS ไม่พบ API ไม่รู้จักหรือ asset ในเครื่องที่หาย
- ชุดทดสอบระบบใช้ฐาน SQLite ในหน่วยความจำ รวมการตรวจ session การแบ่งหน้า การนำเข้า/ส่งออก การซ่อนการ์ด และสิทธิ์ผู้ใช้
- เพิ่ม regression test ให้ API adapter ส่งสถานะเมนูเฉพาะเมื่อยืนยัน session สำเร็จ เก็บ token ในหน่วยความจำเพื่อรองรับกรณี storage ใช้ไม่ได้ และล้างสถานะเมื่อ logout
- ทดสอบ DOM/CSS แยกอีก 10 รายการด้วย jsdom และ PostCSS: ทุกหน้าอ้างอิง V16 ครบและคง ID เดิม, CSS parse ได้, เริ่มเมนูได้ทั้ง 9 หน้าใช้งาน, ควบคุมเมนูตามสิทธิ์/การซ่อน, กรณีอ่านเมนูล้มเหลวและ session หมด, การย้ายปุ่มไม่ทำ handler หาย, เมนูคำสั่งสินทรัพย์และ Sheet, ค้นหา/กรองหน้าแรก, Drawer/คีย์บอร์ด/หน้า login, การอัปเดตแท็บและ Notes ที่ยุบเริ่มต้น
- ตรวจ SHA-256 ของ `Cloudflare-Worker/worker-copy.txt` ตรงกับไฟล์ `worker_copy.txt` ที่ผู้ใช้ส่งมา

คำสั่งตรวจที่รันจากรากโปรเจกต์:

```sh
node worker/scripts/check.mjs
node worker/scripts/audit.mjs
node --test worker/tests/*.test.mjs
```

ผลทดสอบ DOM เป็นการจำลองโครงสร้างและเหตุการณ์ ไม่ใช่การเรนเดอร์ภาพด้วยเบราว์เซอร์จริง

## ส่วนที่ยังตรวจไม่ได้

ยังไม่ยืนยันภาพหน้าจอจริง ขนาดตัวอักษรหลังเรนเดอร์ การล้นของตาราง/Sheet บนทุกอุปกรณ์ กล้อง เสียงจริง การพิมพ์จริง และการเชื่อมต่อกับ production เครื่องมือพรีวิวไม่สามารถเชื่อมต่อ localhost และ Computer Use หยุดเพราะตรวจสอบ URL ปัจจุบันของ Chrome ไม่ได้

แนะนำให้ตรวจหน้าแรก หน้าสต็อก หน้าสินทรัพย์ และฟอร์มล็อตบนหน้าจอจริงก่อนอัปเดตเว็บใช้งาน รวมถึงตรวจ TV กับการตั้งค่าสี/ขนาดที่องค์กรบันทึกไว้
